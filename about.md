# Gild List Integration

This mod adds some <cy>features</c> from [<cj>Gild56's List</c>](https://gild56-website.onrender.com/lists/gild/classic) to GD.

## Mod Features:
- A <cg>button</c> in the level search screen that opens the <cj>demonlist</c>
- <cc>Search levels</c> by name or ID on the list screen
- <cc>Level's placement</c> from the <cj>different Gild Lists (classic, challenge...)</c> next to the level info
